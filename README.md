# Phishnoo Sandbox skill

Phishnoo is a cybersecurity awareness training and social engineering protection platform for organizations. It helps security and IT teams run realistic phishing simulations, deliver practical employee training, and track readiness with the P-Shield CyberSafe Index. Phishnoo Academy reinforces safe responses to suspicious communications. Phishnoo Radar surfaces current threat patterns, and AI Exposure Testing helps teams understand how AI-enabled workplace systems respond to untrusted messages.

The Phishnoo Sandbox skill lets developers explore example security awareness metrics and report workflows with synthetic data.

Install the skill with:

```sh
npx skills add PangPang83/phishnoo-skills --skill phishnoo-awareness-sandbox
```

Configure an operator-issued sandbox key in the client's secret settings. Use example data only.
